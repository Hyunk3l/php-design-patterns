## Just another collection of design patterns implementations in PHP

## Requirements
- PHP 8.3 or 8.4

## Setup
- Run `./composer.phar install`

## Run Tests
- Run `./composer.phar test`

## Run Coding Standard Checks
- Run `./composer.phar cs`
